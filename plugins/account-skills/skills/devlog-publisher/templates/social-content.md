## X/Twitter Thread Template

**Tweet 1 (Hook):**
{The most surprising, contrarian, or attention-grabbing statement from the insight. Must stand alone. Under 280 characters.}

**Tweet 2-3 (Context):**
{Set up the problem or situation. What were you working on? What went wrong or what did you discover?}

**Tweet 4-7 (The Meat):**
{One technique/insight per tweet. Include descriptions of code that would appear in screenshots. Each tweet self-contained but building on the narrative.}

**Tweet 8-10 (Results + Nuance):**
{What happened? What did you learn? Any caveats or edge cases?}

**Tweet 11 (CTA):**
{Link to blog post. Invitation: "What techniques have you found working with [tool]?" or similar engagement question.}

**Thread rules:**
- 7-12 tweets total
- Each tweet under 280 characters
- No tweet starts with "Thread:" or "🧵"
- Describe code screenshots inline (e.g., "Here's the actual ffprobe output that revealed the bug:")
- Tag relevant accounts sparingly (1-2 max, only if genuinely relevant)
- No engagement bait ("Like and RT if you agree!")
