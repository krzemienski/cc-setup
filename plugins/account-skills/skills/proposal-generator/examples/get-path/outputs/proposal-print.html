Overview

Goals

Get Path is an AI-powered career and learning-pathway web app that turns a person's current skills and target role into a personalized, step-by-step skill roadmap. It serves early-career professionals and career-changers who know where they want to go but not how to get there.

G1 · Personalized roadmaps

Let any user go from a target role to a concrete, ordered skill roadmap in under five minutes.

G2 · Trustworthy AI recommendations

Generate roadmap steps grounded in a curated skills graph so suggestions feel credible rather than generic.

G3 · Visible progress

Give users a clear way to track which roadmap milestones they have completed and what comes next.

G4 · Validated v1 launch

Ship a lean, production-deployed MVP that real users can sign up for and complete an end-to-end roadmap flow.

Assumptions
  • Client provides brand assets (logo, colors, fonts) and approved copy for the three launch career tracks.
  • Scope is a single responsive web platform; no native mobile app.
  • Client supplies or approves an LLM provider API key and accepts usage-based AI costs.
  • A single English-language locale is sufficient for v1.
  • Subject-matter input for the curated skills graph is available from the client or a designated expert.
  • One staging and one production environment are sufficient for launch.
Constraints
  • v1 is web-only and English-only.
  • Recommendations are limited to the three seeded career tracks at launch.
  • Email/password authentication only; no third-party SSO in this build.
  • AI roadmap generation is grounded in the curated skills graph rather than open-ended web browsing.
  • Fixed five-week timeline aligned to the five delivery phases.
Out of scope
  • Native iOS and Android applications.
  • Single sign-on (Google/GitHub/SAML) and enterprise identity integration.
  • Payments, subscriptions, or billing.
  • Integrations with external course catalogs or job boards.
  • Multi-language / localization support.
  • Admin CMS for non-technical editing of the skills graph.
