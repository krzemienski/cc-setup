# MDF ROI

Market development funds are the easiest partner spend to waste, because the return is rarely
measured. A partner asks for co-marketing money, you grant it on their tier, an activity happens,
and nobody checks what pipeline it produced. Multiply that across a program and MDF becomes a line
item no one can defend. The fix is treating every MDF dollar as an investment with a required
return.

## The core metric

```
MDF ROI = attributed pipeline generated ÷ MDF spent
```

Measure it per activity and per partner. Set a threshold (a common default: 5:1 pipeline-to-spend,
or a positive closed-won return over a defined window). Fund what clears it; cut what doesn't.

You need the sibling metric too:

```
MDF closed-won ROI = attributed closed revenue ÷ MDF spent
```

Pipeline ROI tells you the activity generated interest; closed-won ROI tells you it generated money.
An activity with great pipeline ROI and terrible closed-won ROI is generating unqualified interest:
a targeting problem, not a spend problem.

## Making MDF measurable

The reason MDF ROI is rarely known is that the spend isn't tied to attributable pipeline. Fix the
structure:

1. **Proposal-based**: the partner proposes an activity with an expected pipeline outcome before
   funds are granted. No proposal, no funds.
2. **Tracked to a source**: the activity gets a campaign/source tag so the pipeline it generates is
   attributable back to it. Untracked MDF is unmeasurable by definition.
3. **Milestone-funded**: funds release on activity completion and reported results, not upfront.
4. **Reviewed on a window**: pipeline within, say, 90 days; closed-won within the sales cycle
   length. Set the window to your motion.

## The decision it drives

At each review, every partner's MDF sorts into:

- **Renew / increase**: cleared the threshold. This partner turns co-marketing money into pipeline.
- **Hold / redirect**: pipeline but no conversion. Fix targeting or offer before spending more.
- **Cut**: no attributable return after a fair window. Reallocate to partners who produce.

MDF is a portfolio, same as the partner base. A few activities carry the return; many produce
nothing. The discipline is moving money toward the winners, not spreading it evenly to keep everyone
happy.

## MDF ROI mistakes

- **Entitlement funding**: MDF granted on tier, not on an activity with an expected return.
- **No source tagging**: spend that can't be tied to pipeline is spend you can't evaluate.
- **Measuring activity, not outcome**: "we ran three webinars" is not a return.
- **Upfront, unconditional funds**: no milestone gate, no results requirement, no claw-back.
- **Never cutting**: a program where no MDF is ever pulled is a program with no ROI discipline.

## Output of an MDF review

1. Per activity/partner: spend, attributed pipeline, pipeline ROI, closed-won ROI.
2. Each sorted into renew / hold / cut against the threshold.
3. The reallocation recommendation: where the cut money should go.
4. Any structural gap flagged (e.g. "spend isn't source-tagged, so ROI can't be computed: fix
   tracking first").
