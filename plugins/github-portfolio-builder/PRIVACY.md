# Privacy notice: GitHub Portfolio Builder

Last updated October 3, 2026.

GitHub Portfolio Builder is a package of instructions and reference text. It has no publisher-operated service, account, telemetry, or storage. The publisher does not receive or retain review content through this plugin.

## Data used in a review

The skill asks Claude to read the GitHub profile or repository named by the user, a small number of related repositories for a profile review, and linked websites or demos when needed to support a finding. Public profile and repository material may include names, contact details, and other personal data. A private target is reviewed only when the user supplies it and their Claude environment already has access.

Claude, GitHub, any optional GitHub MCP, and any linked site may process requests or content according to their own terms, permissions, and retention settings. Requests to GitHub or linked sites expose the requested URL and normal request metadata to those operators. The package does not require a GitHub token for public targets or install an MCP server.

The skill instructs Claude to make recommendations without changing repositories, profile settings, or pins, and not to upload private repository content to a linked site. These are instructions; the host's enabled tools and permissions determine what actions are technically possible. Users who need strict read-only access should configure it in their Claude environment and any optional GitHub MCP.

For questions about this package, use the [repository issue tracker](https://github.com/RachaelQuisel/github-portfolio-builder/issues). For Claude, GitHub, or linked-site data controls, use those providers' privacy settings and policies.
