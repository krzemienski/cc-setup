# Changelog

All notable changes to northstar are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/), and the project adheres to
semantic versioning.

## [0.1.0] - 2026-05-24

### Added

- `goal-engineering` skill — transforms any prompt, document, bug report, or
  backlog into a rigorous `/goal` completion condition, with references on the
  evaluator model and per-input-type recipes.
- `goal-orchestration` skill — runs a crafted condition across hand-off,
  headless, and self-orchestrated execution modes, with references on execution
  modes and monitoring and recovery.
- `condition-library` skill — ten parameterized `/goal` condition templates for
  recurring kinds of work.
- `/goal-craft` command — turns any input into a ready-to-paste `/goal`
  condition.
- `/goal-run` command — executes a goal in hand-off, headless, or
  self-orchestrated mode.
- `/goal-status` command — inspects and recovers a running or stalled goal.
- `LICENSE` (MIT) and this changelog.
